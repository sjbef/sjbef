# SJBEF Logos & Branding Assets

This directory contains official Saint-Jean-Baptiste Educational Foundation (SJBEF) logos, crests, badges, and other brand identity assets.

## Files to Store Here

- **Main Logo**: High-resolution versions of the SJBEF seal or logo (PNG with transparent backgrounds preferred, SVG also supported).
- **Alternative Logos**: Sub-chapter logos (Somerset, Westport, North Attleboro), bicultural icons, and bilingual banners.
- **Social Media Icons**: Cohesive square icons or banner headers for official online presence.

## How to Reference

- Any asset here is served at `/images/logos/[filename]`.
- Example: `/images/logos/sjbef_logo_primary.png`
