# SJBEF Site-Wide UI Graphics

This directory contains static visual assets used to build the website interface, such as hero banners, background patterns, generic icons, and decorative illustrations.

## Asset Tips
- Prefer SVG or highly optimized WebP/JPEG formats.
- For large background images or hero banners, compress the file (e.g. via tinypng.com) to ensure the website loads instantaneously for all visitors.

## How to Reference
- Files here are served at `/images/site/[filename]`.
- Example: `/images/site/hero_french_heritage.jpg`
